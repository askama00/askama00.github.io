在 VMware 中安装银河麒麟服务器版 V11（Swan25）

国产化替代、信创适配这类场景里，银河麒麟（Kylin）大概是绕不开的一个系统。这次为了验证一套软件的兼容性，我在 VMware 里装了一台 银河麒麟高级服务器操作系统 V11（Kylin Linux Advanced Server V11，代号 Swan25），把过程记下来，主要是给自己留个档，顺便给同样要装的人一个参照。

我这次的环境

  • VMware，虚拟磁盘 512 GiB（截图里磁盘显示为 VMware Virtual S (sda)）
  • 镜像：Kylin Linux Advanced Server V11（Swan25），x86_64
  • 装完的内核：6.6.0-32.7.v2505.ky11.x86_64

ISO 挂到虚拟光驱，开机从光驱引导。麒麟 V11 用的是 Anaconda 系安装器，跟 RHEL / CentOS 一个路数，图形界面点就行。真正要动脑子想的其实就两处：软件选什么、盘怎么分。

一、引导菜单

开机先到 GRUB，标题是 Kylin Linux Advanced Server V11，三个选项：

  • Install Kylin Linux Advanced Server V11 —— 直接装；
  • Test this media & install … —— 先校验安装介质再装；
  • Troubleshooting —— 排障入口。

底部有个 Automatic boot in 19 seconds... 的倒计时。它到底会不会在倒计时结束后自动进第一项，我没去验证，反正我是手选的。ISO 是下载来的、怕不完整可以走一遍 Test this media 先验一下；我直接 Install。

二、语言与区域

中文 → 简体中文 → 继续。选完之后键盘布局、时区（亚洲/上海）会按中文环境默认好，后面摘要页还能改。

三、安装信息摘要

这是总控台，所有配置都从这儿进、改完再回这儿。界面分四块：

区域包含项
本地化键盘、语言支持、时间和日期
软件安装源、软件选择
系统安装目的地、网络和主机名
用户设置Root 账户、创建用户

刚进来时是：安装源「本地介质」、软件默认「带 UKUI GUI 的服务器」、安装目的地「已选择自动分区」、Root「密码未设置」、创建用户「不会创建任何用户」。

底部那句「请先完成带图标标记的内容再进行下一步」要留意：带告警图标的项没弄完，右下角「开始安装」就是灰的，得把 root 密码设了才会亮。

四、软件选择

基本环境四选一：

  • 最小安装：只装最基本的功能；
  • 服务器：带常用管理组件的服务器环境；
  • 虚拟化主机：最小虚拟化主机；
  • 带 UKUI GUI 的服务器：在服务器基础上带 UKUI 图形界面。

默认是「带 UKUI GUI 的服务器」，会顺带装上图形界面。我这台只拿来跑命令行，就换成了 「最小安装」，能少装就少装，后面缺什么再补；要图形界面就选带 GUI 那个。

右边「已选环境的附加软件」一堆可选项（调试工具、DNS、文件及存储、FTP、GNOME 应用、虚拟机代理、邮件、性能工具、远程管理、Windows 文件服务器……），我一个没勾，用得上再说。

点完成回摘要。

五、分区

摘要里「安装目的地」默认是自动分区，我改成了手动分区。进去是空的，提示还没建挂载点。我没自己一格一格加，直接点了「点击这里自动创建它们(C)」，让它按 LVM 给我生成一套，下面就是生成完的样子。当然也可以自己点「+」手动加，两种都行，我图省事。

512 GiB 的盘，自动创建出来是这样：

挂载点 / 用途大小文件系统说明
BIOS Boot1024 KiB—引导用
/boot1024 MiB默认引导分区
swap7.83 GiBswap交换分区
/503.17 GiBxfs根分区

根分区走的 LVM：VG 叫 klas，根逻辑卷在摘要里显示为 klar-root、交换卷为 klar-swap，根文件系统 xfs，「重新格式化」也勾着。左下角可用空间就剩 1.97 MiB，等于整块盘都分完了。

点完成会弹「更改摘要」，把要执行的操作一条条列出来，这次 11 步：清分区表 → 建 GPT → 建 sda1/sda2/sda3 → 在 sda3 上建 LVM 物理卷 → 建卷组 klas → 建根逻辑卷并格式化成 xfs → 建交换逻辑卷。看着没问题就点接受更改。

六、回到摘要

安装目的地变成「已选择自定义分区」。但 Root 还是「密码未设置」，开始安装照样灰着——分区只是其中一项，root 密码没设还是开不了工。

七、Root 密码

点 Root 账户，选「启用 root 账户」，设密码并确认。系统对密码有要求，得凑够三类字符，我用的是大写 + 小写 + 数字，强度显示「强」。下面还有个「使用 SM3 算法加密密码」，国密算法，按需勾，我没勾。

顺带说下 root 的隐患，不是劝你别用：root 权限最大，误删、误改、被爆破都是全局性的，密码别太随意，也别到处复用。要不要再建个普通用户日常用、root 只留着应急，看你自己习惯——我这次就只用了 root。

八、开始安装

设完 root 密码回摘要，Root 变成「已设置 root 密码」，「开始安装」终于能点了。

点下去进进度页，第一条是「正在 /dev/sda1 上创建文件系统 biosboot」，然后依次格式化 /boot、swap、根分区，再把软件包解包写进去。到这一步才真正动盘——摘要页底下那句「在点击开始安装按钮前我们并不会操作您的磁盘」说的就是这个。时间看机器性能和装的东西多少，等它跑完。

九、安装完成、重启

进度条走完显示「完成！」「Kylin Linux Advanced Server 已成功安装并可以使用！重启系统然后使用吧。」点重启。底部还提了许可协议的位置：/usr/share/kylin-release/EULA。

十、首次启动：同意协议

重启后 GRUB 里出现启动项：Kylin Linux Advanced Server (6.6.0-32.7.v2505.ky11.x86_64) V11 (Swan25)。第一次进系统不是直接到登录界面，先来个文本初始化向导，列了两项：

  1. License information（许可协议，没接受）
  2. User creation（没建用户）

我只建了 root，所以这儿不用再建用户，选 1 把协议同意了，按 c 继续就行（q 退出、r 刷新）。协议不同意是进不去的。要不要在这儿顺手建个普通用户，看你需要，我没建。

装完我会先看几眼
