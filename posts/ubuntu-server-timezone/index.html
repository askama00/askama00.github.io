UbuntuServer调整时区并开启校时

📅 2026年10月02日 📚 系统配置 ⏳ 约 1 分钟 👁 – 次浏览
目录 2 节 ▾
  • 设置时区
  • 开启自动校时

UbuntuServer安装之初，如果选择的是英文安装，默认时间应该是UTC+0，即比北京时间晚8小时，如果我们的服务器是为国内用户服务的，那这个时间就会影响我们一些软件和服务的时间，所以我们有必要修改时区，下面提供一种简单修改为上海时区的方案。

设置时区

我们使用timedatectl来设置时区是一种十分方便的方式，可以执行如下命令直接设置为上海时区

sudo timedatectl set-timezone Asia/Shanghai

设置好之后，我们可以通过date命令判断是否修改成功，如果修改成功会有如下类似输出

2026年 10月 02日 星期五 22:07:57 CST

开启自动校时

上面设置好时区时候，时间基本就会正常了，但是有时我们的Ubuntu的时间跟真时的时间会有偏差，或者系统运行过好一段时间之后会有偏差，如果我们的服务器的业务是时效性很强的，比如一些物联网业务，那就会造成业务出现问题，所以我们最好开启自动校时，来确保系统时间的准确，执行如下命令就能开启自动校时

sudo timedatectl set-ntp true

我们也可以执行如下命令，手动同步一次时间

sudo chronyc makestep

这样我们就完成了时区设置和时间同步
