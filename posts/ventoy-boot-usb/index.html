Ventory启动盘制作工具下载

本博客主要讲解启动盘的制作和使用，启动盘制作在Windows上可以使用很多工具，作者比较喜欢用的是Ventory和Rufus，很多启动盘制作工具和Rufus一样只能提前指定要用的iso镜像文件，然后将整个U盘制作为这个iso文件的启动盘，如果想要制作多个系统的启动盘，就需要多个U盘，或者自己做一个可以多系统安装的iso，有一定的难度，所以本博客主要选择使用Ventory工具作为我们的启动盘制作工具，该工具制作好启动盘之后，U盘会被分为两个分区，一个是很小的引导分区用来引导启动盘，其余的部分能够当作U盘使用，将想要使用iso文件放入其中，就能实现自由灵活得地选择想要安装的系统。

制作启动盘

可以在设备下拉框选择对应的U盘设备，然后点击安装，等待进度条读完，即可完成Ventory启动盘的制作，如果是已经制作为Ventory启动盘的U盘设备，可以点击升级按钮来升级版本，升级不用清空U盘，但是安装会格式化U盘，请确保U盘内的重要文件已经做好备份。然后我们就得到了一个启动盘，我们把想要安装的操作系统的iso镜像文件放入其中即可，此启动盘可以安装Windows和Linux的iso文件，如果你的U盘空间足够，你完全可以把你想用到的所有iso文件都放入其中。

进入系统安装界面

进入启动盘系统

我们的电脑在启动后默认会进入已经安装的操作系统，但是我们要重装电脑，就要进入U盘内的系统，这个时候我们可以用两种方式进入，但是首先我们都要先关闭BIOS的安全启动设置。

方法一：进入BIOS调整引导启动顺序

1、关闭安全启动

首先我们要进入电脑主板的BIOS，然后在其中找到安全启动的配置，关闭安全启动，不然我们在进入U盘系统的时候大概率会出问题，不同品牌的主板进入BIOS的按键不同，我们需要在开启电脑之后疯狂连续按下对应按键，以此来进入BIOS系统，不然会正常进入对应的引导系统，无法进入BIOS，不同品牌的按键对应表格如下：

主板品牌进入 BIOS 按键备注
华硕 (ASUS)Del 或 F2笔记本多为 F2，台式机多为 Del
微星 (MSI)Del部分型号为 F2
技嘉 (Gigabyte)Del部分型号需快速连按
华擎 (ASRock)Del 或 F2优先尝试 Del
联想 (Lenovo)F2 或 Fn + F2部分机型需按机身侧边“Novo”小孔
惠普 (HP)F10进 BIOS 选 F10，进引导菜单选 F9
戴尔 (Dell)F2出现 Logo 时连续敲击
宏碁 (Acer)F2部分型号需 Fn + F2
微软 (Surface)音量+关机状态下，按住音量+再按电源键
七彩虹 (Colorful)Del-
铭瑄 (Maxsun)Del-
梅捷 (Soyo)Del-

如果我们不知道自己电脑的主板品牌的话，可以在开机的时候可以观察到，每个电脑开机一般会先出现主板品牌的图标或文字，可以以此获取主板品牌。上面的表格的按键作为参考，因为BIOS新老版本不一样，对应的按键可能会改变，如果使用表格里面的按键无法进入BIOS，那么就要自己在网上查询自己的主板如何进入BIOS。

下面以我自己的电脑为例，简单介绍一下过程，可以给各位当个参考：

1、进入BIOS

我的主板是微星的，硬件为2025年左右的，所以BIOS是这个样子，然后我通过点击上面的高级模式可以进入到高级配置页面

在我这里是点击安全，然后点击安全引导，就找到了安全启动的设置，关闭之后保存BIOS设置即可

然后我们可以还到高级模式的Settings设置主页面，进入启动目录下，调整引导启动顺序，将你的启动盘的引导调到第一位，然后保存，这样在你U盘插入的状态下启动电脑，应该就能直接进入U盘的系统了

首先，我们还是要关闭BIOS的安全启动，方法参考方法一的介绍，这里不再赘述。

然后，我们在开机的时候狂点自己主板品牌对应的进入引导界面的按键，与方法一的BIOS类似，不同品牌的主板进入引导界面的按键是不一样的，统计表格如下：

安装系统

经过上面的操作之后，我们就进入到镜像文件的启动程序里面了，下面我们主要以win11操作系统为例说明，每个操作系统的步骤都不一样，所以本文并不能面面俱到，不过可以作为参考，下图极为进入win11的初始图

因为我的镜像是多版本镜像，所以这里会让我选择要安装的windows版本，这里我选择安装专业版，这里可以根据自己的个人情况选择

许可条款，直接确认就好

这里是要进行磁盘划分了，我这个是在虚拟机截图的，所以有一个新磁盘，不同的磁盘按照开头的编号划分，比如你的电脑有两块磁盘，那么就会有磁盘0和磁盘1，每个磁盘可以分区，所以你可能会看到磁盘0有好几行，其实是不同的分区，他们还是属于一个磁盘，下图就是点击创建分区之后，系统自动分盘的效果

系统自动把我的磁盘分为了三个分区，其中分区1是引导分区，跟我们的启动盘一样，我们启动系统需要一个引导分区，里面存放了一些引导文件，用来引导硬件来如何启动系统，启动哪个系统，分区2是微软的保留分区，不用管，分区3就是一个可用分区，我们其实可以把分区3继续拆分，但是我只想要一个C盘，所以我就不拆分了，这里我选择分区3然后点击下一页，那么就会把系统安装进分区3，此分区原有的文件都会消失，然后这个分区就是以后的C盘了，如果我把分区3拆分为了分区3和分区4，然后依然选择分区3安装，那么分区3是C盘，分区4可以作为D盘存在。

同样的，如果你现在是要对一个已经安装好的电脑重装系统，到了这一步，有分区3和分区4，其中分区4是D盘，你放了一些文件，这个时候你不对分区4进行任何操作，只是选中分区3重装系统，那么新系统装好之后，D盘里的东西还是存在的，这就是分盘的意义，在系统出问题要重装系统的时候，可以便利地保留文件到C盘之外的其他磁盘，只要重装系统的过程中不误操作，文件就还能保留下来

然后我们就到了确认页面，如果确保信息无误，那就可以点击安装

然后就进入了自动安装界面，这期间电脑可能会重启几次，不必惊惶，慢慢等待即可

到了这个界面，实际上系统已经安装到了你选择的磁盘分区，这里是开始初始化系统了，我们按照提示一步一步下一步就行

到这个界面之后，我们就要登陆了，如果你不想登陆微软账号，win11有一些办法可以绕过登陆，本文只介绍一种最简单的版本，就是我们在输入账号页面随便打一串能通过但是毫无意义的字符串，可能是别人的账号，不过应该不会有人的账号是这样很随机的字符串，然后点击下一步，会跳到密码或者邮箱验证界面，如果是密码界面，则随便打一串密码，点击登陆，会提示密码错误次数过多，然后会问你是否要用本地账户，点击用本地账户就行了，如果是邮箱验证界面，那就点击密码验证，跳到密码页面再操作
